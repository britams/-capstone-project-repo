## 말벌 자동 마킹 트랩 (팀 초벌)

상용 말벌 트랩 「야생 말벌 포획기」에 얹는 **추가 모듈**. 트랩에 잡힌 말벌을 카메라로 확인하고, 운용 모드에 따라 처리한다.

| 모드 | 동작 |
|---|---|
| 방제 모드 | 구별 없이 전부 가둠 + 촬영·종 분류 로그 |
| 조사 모드 | 여왕벌은 가둠, 일벌은 흉부에 수성 아크릴 마커로 점 → 먹이 → 방생, 다시 잡히면 로그 → 먹이 → 방생 |

- 지도교수: 김성관 교수님 · 팀장 이서현 · 팀원 이승준
- 지금 상태: [`docs/00_새채팅_인수인계_2026-10-28.md`](docs/00_새채팅_인수인계_2026-10-28.md)

## 폴더

| 폴더 | 내용 | 담당 |
|---|---|---|
| `docs/` | 시작키, 인수인계, 분업계획, GitHub 사용법 | 서현 |
| `ai-log/` | AI 명령사항 로그 (각자 파일) | 각자 |
| `design/` | 재설계 문서(D0~), 설계 변수표, 역학계산, 인터페이스 정의서 | 서현 (인터페이스는 공동) |
| `cad/` | FreeCAD 생성 스크립트(.py), 모델(.FCStd), 도면 | 서현 |
| `vision/` | VespAI 실행, 종·계급·표식 판별, 라즈베리파이 설정 | 승준 |
| `control/` | 아두이노 코드, 배선, Pi ↔ 아두이노 통신 | 승준 |
| `purchase/` | BOM, 견적, 예산 장부 | 승준 |
| `inventory/` | 보유 물품 목록과 활용계획 | 서현 → 승준 |
