# 낮·밤 동작 — 밤에는 전부 가둠, 낮에만 처리 (승준 결정, 2026-11-06 20:23, CAP-AI-SJ-46)

## 결정 (승준)
- **밤에는 방생하지 않는다.** 해 진 뒤 들어온 말벌은 전부 상용 트랩 포획통으로 (가둠).
- 해 질 때 마킹실에 남아 있던 말벌도 방생하지 않고 포획통으로.
- **아침(해 뜬 뒤)부터만** 판별 → 누르기 → 찍기 → 급이 → 방생.

## 왜 (캐드에서 따라온 것)
방생부는 '짧은 목 30 mm + 위가 하늘로 열린 굴뚝'이고 출구 조명이 없다 (SJ-44·45). 굴뚝은 **햇빛으로 밝을 때만** 말벌을 위로 이끈다 → 밤엔 방생이 안 된다.

## 시간
- `control/pi/daynight.py` — 날짜로 해 뜸·짐 계산 (공주, NOAA 근사식). 11/06: 해 뜸 06:59, 해 짐 17:31 (6/21: 05:13·19:52, 12/21: 07:39·17:19)
- 처리 시간 = 해 뜸 + 30분 ~ 해 짐 − 30분 (굴뚝이 충분히 밝을 때만)
- Pi 5 RTC 배터리로 날짜·시간 유지 (회로 BOM에 이미 있음)

## 밤 상태 (부품 추가 없음)
| 부품 | 밤 | 낮 대기 |
|---|---|---|
| 방생 문 REL | 닫힘 | 닫힘 (방생 때만 열림) |
| 입구 문 IN | 열림 | 열림 |
| 격리 문 CAP | **열림** → 마킹실을 지나 격리 통로 → 포획통 | 닫힘 |
| 마킹실 조명 | 끔 (포획통 쪽 하늘빛이 더 밝음) | 판별 때 켬 |
| 펜 | 올림 | 올림 |
| 바닥 | 0 | 0 |

## 방생 (낮)
마킹실 조명(위·아래) 끔 → 방생 문 엶 → G5·G5b → G6(목 위) 통과 → 0이면 닫음. **출구 조명 켜기·깜빡이기 없음** (SJ-45).
해 짐 − 30분이 되면 처리 중인 말벌도 방생 대신 격리 문으로 (포획통).

## 시험
- `python control/pi/daynight.py` → 해 뜸·짐 출력 + 판정 시험 통과 (07:10 밤, 09:00 낮, 17:20 밤, 22:00 밤)
