|---|---|---|
| 1 | 펌웨어·파이썬 클라이언트 작성 완료. PC에서 **아두이노 흉내 시뮬레이션**으로 명령·이동·동시 이동(X·Y)·하중 정지·문·펜·워치독 확인 | [확실] 시뮬레이션 / 실물 `미검증` |

## 2. 핀 배정 (UNO)

| 구동기 | 도면부호 | 부품 | UNO 핀 |
|---|---|---|---|
| F 바닥 승강 | 153 | 28BYJ-48 + ULN2003 | D2 D3 D4 D5 → ULN2003 IN1~IN4 |
| X 마커 X | 215 | 28BYJ-48 + ULN2003 | D6 D7 D8 D9 |
| Y 마커 Y | 209 | 28BYJ-48 + ULN2003 | D10 D11 D12 D13 |
| IN 입구 문 | 112 | SG90/MG90S | A0 (신호) |
| CAP 격리 문 (포획통) | 170 | SG90/MG90S | A1 |
| REL 방생 문 | 176 | SG90/MG90S | A2 |
| PEN 펜 들기 | 205 | SG90 | A3 |
| 하중 센서 | 148 | 로드셀 + HX711 | DT A4, SCK A5 |
| 진입 감지 | 114 | 적외선 빔 | **Pi GPIO** (UNO 핀 없음) |

전원: 서보·ULN2003의 + 는 **별도 5V**, 모든 GND는 UNO GND와 연결. UNO는 USB(Pi)로 전원·통신.

## 3. 명령 (시리얼 115200, 한 줄 = 명령 하나)

| 명령 | 뜻 | 응답 |
|---|---|---|
| `PING` | 살아 있나 | `OK PONG` |
| `STATUS` | 위치·하중·펜 | `OK STATUS F=0.000 X=0.000 Y=0.000 MOVING=- LOAD=0.0 PEN=UP` |
| `MOVE <F/X/Y> <mm>` | 절대 위치로 이동 (X·Y 동시 가능) | `OK MOVE …` → 끝나면 `DONE MOVE X 5.000` |
| `PRESS <g> [<mm>]` | 바닥을 올리다 하중 ≥ g면 정지 (상태 머신 4) | `DONE PRESS <mm> <g>` 또는 `DONE PRESS LIMIT …` |
| `DOOR <IN/CAP/REL> <OPEN/CLOSE>` | 문 | `OK DOOR` |
| `PEN <UP/DOWN>` | 펜 들기/놓기 (상태 머신 6) | `OK PEN` |
| `STOP` | 스테핑 전부 정지 | `OK STOP` |
| `ZERO <축> <mm>` | 지금 위치를 mm로 정함 (원점 스위치 대용) | `OK ZERO` |
| `SPEED <축> <µs>` | 반걸음 간격 (기본 1000, 최소 800) | `OK SPEED` |
| `LIMIT <축> <min> <max>` | 소프트 한계 (기본 F 0~36.5, X −18~18, Y −40~18 — 인터페이스 2차 잠정값) | `OK LIMIT` |
| `HOLD <축> <0/1>` | 멈춘 뒤 코일 유지 (기본 F만 1 — 바닥이 스프링에 밀려 내려가지 않게) | `OK HOLD` |
| `SERVO <이름> <deg>` / `SETDOOR <이름> <열림> <닫힘>` | 서보 각도 보정 | `OK …` |
| `LOAD` / `TARE` / `CAL <g/raw>` | 하중 읽기 / 영점 / 배율 | `OK LOAD <g> <raw>` |
| `WATCHDOG <s>` | s초 명령 없으면 정지·펜 들기 | `EVT WATCHDOG_STOP` |
| (켜질 때) | 대기 상태: 입구 열림, 격리·방생 닫힘, 펜 들기 | `EVT READY trap_controller v0.1` |

오류: `ERR LIMIT`(한계 밖), `ERR AXIS`, `ERR UNKNOWN` 등.

## 4. J6 시험 절차 (승준, 실물)

준비: UNO 1, ULN2003+28BYJ-48 1세트(보유), MG90S 1(보유), 5V 별도 전원, 브레드보드·점퍼선. 서보·스테핑 추가분은 구매 후.

1. Arduino IDE 설치 → `trap_controller.ino` 열기 → 보드 Arduino Uno → 업로드
2. PC에서 `pip install pyserial` → `python control/pi/trap_link.py COM3` (포트 번호는 장치 관리자) → `EVT READY` 확인
3. **스테핑 (보유 1세트를 X 자리 D6~D9에 연결)**
   - `MOVE X 5` → 축이 돌고 `DONE MOVE X 5.000`
   - **속도 측정**: 축에 테이프 깃발을 붙이고 `MOVE X 8` (리드스크루 1회전 = 8 mm = 4075.77 반걸음) → 1회전 하는지, `time X 8`로 걸린 시간 → mm/s
   - `SPEED X 900` → 다시 측정 → 걸음 빠짐(덜 돎) 없는 최소 간격 찾기
4. **서보 (MG90S를 A0에)**: `SERVO IN 0`, `SERVO IN 90` → 움직임 확인 → 실제 문 각도가 정해지면 `SETDOOR IN 90 0`
5. 영상(휴대폰)으로 각 동작을 찍고, 결과를 `control/` 날짜 파일에 기록: 축, 간격 µs, 측정 mm/s, 걸음 빠짐 여부
6. HX711·로드셀은 구매 후: `TARE` → 알고 있는 무게(예: 동전) 올리고 `LOAD`의 raw → `CAL <g/raw>`

## 5. 서현에게 넘길 것 (인터페이스 정의서 '통신' 행·변경 이력에 기록)
1. **원점 스위치**: 리밋 스위치(마이크로 스위치) 3개(F·X·Y)를 넣으면 켤 때 원점 찾기 가능. 단 **UNO 핀이 남지 않음** → ① 스테핑을 스텝·방향 드라이버(A4988 등, 축당 2핀)로 바꾸면 6핀으로 줄어 스위치 3개 + 여유 생김 (D5 10-6의 NEMA17 검토와 같이 정하면 좋음) ② 아니면 아두이노를 2개로 나눔
2. **속도**: 28BYJ-48 + T8은 약 2 mm/s → Y 편도 58 mm에 약 30 s (인터페이스 2차와 같음). R6(3분) 판단은 서현 D6
3. **전원**: 구동부 5V 별도 전원 필요 (전원 행 '미정' 채울 때 반영)
