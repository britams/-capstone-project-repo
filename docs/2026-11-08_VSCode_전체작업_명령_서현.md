## 1. 새 대화를 열 때 붙여 넣을 첫 메시지 (11/08 밤 갱신, CAP-AI-53)
**한 대화에는 한 가지만.** 아래에서 이번에 할 것 하나를 골라 붙인다. 대화가 길어지면 새로 열고 같은 것을 다시 붙인다.

### 1-A. CAD 대화 (다음에 할 것)
```
나는 이서현이야. 이번 대화는 CAD만 해. CLAUDE.md 대로 시작해: git pull → docs/00_새채팅_인수인계_*.md → docs/2026-11-08_VSCode_전체작업_명령_서현.md → docs/2026-11-08_CAD_D5g_정리_작업지시_서현.md → 내 AI 로그 마지막 항목 → design/인터페이스_정의서.md → cad/README.md.
명령 정리 문서 3-A 순서대로 진행해 (CAD C1~C6 + 펌웨어·회로 쪽이 CAD에 넘긴 확인 4가지).
FreeCAD는 freecadcmd로 스크립트를 돌려 (RPC execute_code는 90 s에 끊김). 기구 치수를 바꾸거나 되돌릴 수 없는 일은 먼저 물어봐.
```

### 1-B. 펌웨어·제어·전기회로 대화
```
나는 이서현이야. 이번 대화는 펌웨어·제어·전기회로만 해 (CAD는 안 함). CLAUDE.md 대로 시작해: git pull → docs/00_새채팅_인수인계_*.md → docs/2026-11-08_VSCode_전체작업_명령_서현.md → 내 AI 로그 마지막 항목(CAP-AI-52 근처) → design/인터페이스_정의서.md → 전기회로/README.md → 관련코딩저장/README.md.
```

## 4. 규칙 (CLAUDE.md에 없는 것 / 이번에 정한 것)
- **코드 폴더는 지금 그대로**: 펌웨어 `design/circuit/firmware/`, 시뮬·pi_link `관련코딩저장/`. 새 폴더를 더 만들지 않는다. `design/circuit/bringup/`은 회로 시험용으로 그대로 둔다.
- **AI 로그 번호**: 쓰기 직전에 `ai-log/AI_명령사항_로그.md` 마지막 번호 + 1 (지금 마지막 CAP-AI-53).
- **커밋**: `[서현] …`. Claude가 직접 commit·push한다. 서현이 VS Code 버튼으로 커밋할 때는 Commit ▼ → **Commit & Push**, 메시지는 `[서현]`으로.
- **받기**: 대화를 시작할 때 `git pull`. 승준이 다시 올리기 전까지는 충돌이 거의 없다.
- **PC 사본**: `Desktop\capstone design\repo\`(문서에 적힌 `capstone design_이서현`은 없음)는 git 레포가 아니다. 바뀐 파일을 복사해 맞춘다 (레포가 원본). 제어·회로 문서는 `제어\`에 번호를 붙여 복사하고, `00_읽는순서.md`에 줄을 더한다 (지금 21번까지).
- **사용량**: 90 %면 저장·push부터 한다. 96 %면 남은 일을 순서대로 로그에 적는다.
- **결정 기록**: 서현이 맡긴 결정은 '(AI 판단, 서현 위임)'. 확실도 [확실]/[가능성 높음]/[추측].
