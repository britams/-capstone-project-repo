## 5. VespAI — 확인한 것 (할 일 ②)
- 논문: O'Shea-Wheller 외 2024, *Commun. Biol.* — https://www.nature.com/articles/s42003-024-05979-z
- YOLOv5s 인스턴스 분할 (ResNet-50 백본), 등검은말벌·유럽말벌 2클래스, 640×640, ViBe 움직임 전처리. 현장은 Raspberry Pi 4, 30초 간격 검출
- 저장소: `hiveeyes/vespai` 페이지 확인 — `models/yolov5-params`(가중치), `monitor/monitor_run.py`(웹캠 + ViBe + YOLOv5), `manuals`. **공식 원본 주소 미검증**
- 보유: Pi 5 + AI HAT+ (Hailo 26 TOPS) + AI 카메라 (IMX500). Hailo로 돌리려면 YOLOv5 → HEF 변환 필요
- 계급(여왕벌·일벌) 판별 없음, 유럽 개체 학습
