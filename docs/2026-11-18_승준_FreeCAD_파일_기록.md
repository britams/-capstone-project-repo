## 3. 다시 만드는 법 (승준 PC FreeCAD, Python 콘솔 또는 MCP)

### 3-1. 프로파일 길이별 색칠
서현 `D5g_full_no`를 열고 다른 이름으로 저장한 뒤:
```python
import FreeCAD as App
d = App.ActiveDocument
col = {610: (0.80, 0.15, 0.15), 320: (0.20, 0.40, 0.90), 156: (0.15, 0.70, 0.25)}
n = {}
for o in d.Objects:
    if not o.Name.startswith('P100') and '2020' not in o.Label: continue   # 2020 프로파일만
    if not hasattr(o, 'Shape') or o.Shape.isNull(): continue
    L = round(max(o.Shape.BoundBox.XLength, o.Shape.BoundBox.YLength, o.Shape.BoundBox.ZLength))
    if L in col:
        o.ViewObject.ShapeColor = col[L]; o.ViewObject.DisplayMode = 'Shaded'   # Flat Lines면 검게 보임
        n[L] = n.get(L, 0) + 1
print(n)   # 기대: {610: 4, 320: 21, 156: 1}
```

### 3-2. 203p 마커 클립 (CAD 좌표 그대로, 마커 축 x 75 · y −40)
```python
import FreeCAD as App, Part
V = App.Vector; cx, cy = 75.0, -40.0; cl = []
for z0 in (435.75, 447.75):                     # 위·아래 클립
    h = 9.5; zc = z0 + h/2
    ring = Part.makeCylinder(9.15, h, V(cx, cy, z0)).cut(Part.makeCylinder(7.3, h+2, V(cx, cy, z0-1)))   # 안 Ø14.6 / 밖 Ø18.3
    tab = Part.makeBox(4.0, 17.05, h, V(80.15, -38.0, z0)).cut(Part.makeCylinder(7.3, h+2, V(cx, cy, z0-1)))
    c = ring.fuse(tab).cut(Part.makeBox(4.0, 1.0, h+2, V(cx-9.15-1, cy-0.5, z0-1)))   # 링 틈 1 mm (끼우기)
    c = c.cut(Part.makeCylinder(1.7, 20, V(70, -25.5, zc), V(1, 0, 0))).removeSplitter()   # M3 구멍 Ø3.4 → HV 판
    cl.append(c)
d = App.newDocument('마커클립_미리보기'); f = d.addObject('Part::Feature', 'C203p'); f.Shape = Part.makeCompound(cl)
```
마커 Ø14.7을 안 Ø14.6 링이 살짝 조임 (PLA, 학교 Craft-Lab 출력 — 주문제작 시트 순위 38).
