## 4. 작업 루프 — CAD를 한 번 고칠 때
1. 양쪽에서 `git pull`. PC pull은 DNS가 가끔 실패한다 → returncode를 보고, 실패면 몇 초 뒤 다시. **HEAD가 바뀐 것을 확인한 뒤에** 돌린다.
   - `git log`로 승준 커밋도 본다. 승준이 주문 파일 (STEP·DXF)을 직접 고쳤으면, 이번 수정에 그것을 모델로 되돌려 넣는다 (`docs/2026-11-18_승준_*.md`의 '아직 안 고친 것').
2. 고치는 스크립트 `cad/<이름>.py`: 처음 돌 때 `split/<문서>_before_<이름>.FCStd`로 백업하고, 다시 돌면 백업에서 시작한다 (몇 번 돌려도 같은 결과). 결과는 `split/_<이름>.json` (valid·거리·개수).
3. 돌리기: `Popen([freecad.exe, 스크립트], cwd=cad, creationflags=0x8|0x200|0x08000000)`. 스크립트 끝의 `os._exit(0)` 때문에 **GUI FreeCAD 안에서 exec 하지 않는다.**
4. 결과 json을 읽는다 → 기준을 못 넘으면 고쳐서 2로. 결과가 그럴듯해도, 바뀐 모양을 바깥선·꼭짓점으로 한 번 직접 본다.
5. 전체 수정 + 검사: `Popen([…\bin\python.exe, cad\run_full.py, <이름>, <먼저 돌릴.py …>], cwd=cad)` → 약 45분 → `split/_harness_<이름>.json`이 PASS/FAIL. 기다리는 동안 짧게 자주 묻지 말고, 30~40분 뒤에 확인하도록 예약한다 (send_later).
6. PASS면:
   - PC에서 `git add -u` → commit·push (CAD 결과).
   - 클라우드 문서도 commit·push.
   - PC 사본과 바탕화면을 맞춘다.
   - GUI의 D5g 두 문서를 닫고 다시 연다 (선택 없음, 등각, 화면 맞춤).
7. AI 로그·`cad/README.md`·(필요하면) 인수인계를 고쳐 push → 서현에게 쉬운 설명.

## 9. 다른 Claude 계정에서 시작할 때
새 계정은 서현 계정의 메모리·지난 대화·예약·GitHub 연결·PC 연결을 모른다. 상태는 **레포에 적힌 것만** 믿는다.
| 없는 것 | 대신 |
|---|---|
| 메모리 (서현 선호) | 1장 '서현 선호' + 시작키 '서현 짧은 명령'에 다 적어 둠 |
| 지난 대화 검색 | 인수인계 · AI 로그 마지막 항목 · `cad/README.md` · 이 문서 |
| GitHub 쓰기 | 공개 레포라 **읽기는 그냥 됨**. push하려면 그 계정에 GitHub (britams) 연결 — 안 되면 AI가 바뀐 파일 목록을 주고 서현이 Chrome으로 올림 (`docs/GitHub_사용법_Chrome.md`) |
| PC (FreeCAD·바탕화면) | 그 계정으로 Claude 데스크톱 앱에 로그인 → 이 채팅을 PC에 연결 → 폴더 연결 (`capstone design`, `capstone design_이서현`). FreeCAD MCP가 그 계정에서도 보이는지 확인 [추측 — 앱 설정이 계정마다인지 PC마다인지 모름]. FreeCAD를 켜고 MCP 애드온 서버 시작 |
| 예약 확인 (send_later)·아티팩트·Docs | 계정마다 따로 — 새로 만든다 |
| xlsx 스킬 (recalc) | 없으면 LibreOffice로 다시 계산 (`soffice --headless --convert-to xlsx`) [가능성 높음] |

**처음 5분 확인** (이게 다 되면 일 시작):
1. 레포 `git log -1`이 GitHub 웹의 마지막 커밋과 같다.
2. PC: `device_bash`로 `ls $HOME/mnt/` → `capstone design` 보임.
3. FreeCAD MCP `execute_code`로 `print(1)` → 1. PC 레포에서 `git pull` → HEAD 확인.
4. `python.exe cad\run_full.py --check` → PASS (모델을 고치기 전 기준).
5. 안 되는 게 있으면 그 줄만 서현에게 말하고, 되는 것부터 한다 (예: FreeCAD 없으면 문서·엑셀만).
