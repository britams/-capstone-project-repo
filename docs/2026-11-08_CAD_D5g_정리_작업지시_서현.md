# CAD D5g 정리 — VS Code Claude 작업 지시 (서현 PC)

정리: 2026-11-08 · 이서현 (웹 채팅 Claude, **CAP-AI-43**)
결정 (서현 11/08): **D5g CAD는 서현이 이어받는다** (총지휘). 승준은 서현이 말할 때까지 쉼. CAD 작업은 VS Code Claude가 서현 PC의 FreeCAD로 한다.
- `cad/`는 분업계획상 원래 서현 편집 폴더다. D5g 스크립트(`cad/D5g_*.py`)는 승준 AI가 만들었지만, 고쳐도 규칙 위반이 아니다.
- .FCStd는 서현만 편집 → 이번에 서현 PC에서 처음 저장한다.

## 0. 알아야 할 것
- **[확실] D5g는 .FCStd가 없다.** `G.make()`로 매번 다시 만든다 (`cad/D5g_frame_detail.py`, 약 55 s). STEP을 내려받는 부분이 있다 (UNO 등).
- **그림은 GUI가 있어야 찍힌다** (`saveImage`). freecadcmd(화면 없음)로는 못 찍는다.
  - → 모델 만들기·검사·저장은 **freecadcmd**로 한다.
  - → 그림은 **FreeCAD를 매크로와 함께 실행**한다 (`FreeCAD.exe <매크로.py>`, 찍고 끝).
  - FreeCAD 설치 경로는 PC에서 찾는다 (예: `C:\Program Files\FreeCAD 1.0\bin\`).
- 렌더 규칙 (CLAUDE.md): **정투영**, 시점 애니메이션 끔. 전체 조립도에는 **2020 프레임 + 상용 트랩**을 반드시 넣는다.

## 2. 하지 말 것
- 승준이 정한 기구 치수(문 하우징, 레일, 급이방, 프레임)를 바꾸지 않는다. 바꿀 필요가 보이면 **멈추고 서현에게 묻는다.**
- 남은 결정(방생 출구 안 1/2, 급이 바닥 높이 370, 3D 프린터 판 크기)은 정하지 않는다 → 목록만 보고한다.
- '미검증' 치수(MOSFET 구멍, 로드셀 구멍 간격, 패널 퓨즈 길이, 만능기판 구멍, T너트)는 실물을 재기 전까지 그대로 둔다.
