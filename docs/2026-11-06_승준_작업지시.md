### 2-2. 펌웨어 (`control/`, Issue #5·#7)
1. UNO 1·2 나누기 (핀표: 회로 문서 1장 — UNO 1 18/18, UNO 2 17/17 + D13 예비)
2. `HOLD F 0`, HX711 **80 Hz** (RATE 다리 5 V), 바닥 올라가는 동안 **표본마다** 비교 (평균 X)
3. **반걸음 간격 686~928 Hz 금지** (스프링 서지 약 808 Hz — 실제 산 스프링 값으로 바뀜, 스크립트가 출력). 지금 1000 µs(1000 Hz)는 괜찮음
4. 캐리지 위치 한계에 닿았는데 힘 < F_p: **≥ 0.4 N이면 '눌림 OK'**, 아니면 '말벌 없음/작음' → 다시 보기
5. 문 닫기: 두 빔 모두 0.2 s 비면 닫기, 하나라도 막히면 다시 열기, 3번 실패면 BLOCKED (`design/algo/A2_문닫기.mmd`)

### 2-3. Pi 코드·비전 (`vision/`)
1. **여왕벌 키포인트 모델** — YOLO 포즈, 점 4개(왼·오른 견판, 머리 앞, 허리). PRESS 뒤 원본 해상도 조각 → **Pi AI HAT+(Hailo)에서 돌아가는지 확인**
2. 배율: 같은 사진의 격자 눈 간격 4.4 mm (FFT/자기상관) × 200/201.5
3. 5장 중앙값 ≥ 4.4 mm → 여왕. 유효 < 3장이면 2 mm 내렸다 다시 → 그래도 안 되면 **계절 규칙** (Pi 시계의 달)
4. 판단 순서·상태 머신은 `design/control_sim/trap_sim.py`의 `PiFSM`이 참고 구현 (시나리오 22/22 PASS)

### 2-4. 시험
- **J7 (새로) 여왕벌 폭 측정 오차**: 표본 7마리 캘리퍼 중순판 폭 vs 격자 아래 카메라 → σ ≤ 0.10 mm면 통과 (`여왕벌_크기측정` 문서 7장)

- J6: 28BYJ-48 rpm·탈조, 문 서보 2위치, 빔 막고 닫기 시험

### 2-5. CAD (승준도 FreeCAD 씀)
- D5f는 `cad/D5f_electrical_layout.py` → `make()` / `check(doc)` / `check_floor(doc)` / `render_all(doc, 폴더)`. FreeCAD에서:
  `import sys; sys.path.insert(0, r"<repo>/cad"); import D5f_electrical_layout as E; doc = E.make(); print(E.check(doc), E.check_floor(doc))`
- **서현 쪽은 CAD를 멈춘다.** 스프링·로드셀 실물 치수가 나오면 `FG` 값(맨 위 dict)만 바꾸고 `check_floor`로 0건 확인 → 커밋 메시지 `[승준]`, `cad/README.md`에 한 줄. .FCStd는 서현만 편집 규칙 → 승준은 **스크립트만 고치고 FCStd는 서현이 다시 만든다** (Issue로 알림)
