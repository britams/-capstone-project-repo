# XY 모터 LM-NK1134 → NEMA17 팬케이크 + T8 — 부딪힘 검사와 판 손 가공 (승준, 2026-11-23)

## 1. 왜 바꾸나 [확실]
- 11/20 주문한 모터뱅크 LM-NK1134 132 × 2 (124,200, 자비)가 **12/4 또는 12/11 도착** → 12/2 시연에 못 맞춤. 모터뱅크에 "재고 길이로 이번 주 / 안 되면 취소" 문자 (답 대기).
- 판(217·YM·XN·CP 등)은 이미 주문 → 설계는 못 바꿈 (승준).
- 대체: 네이버 스마트스토어 '내써팝' **TM 스크류 일체형 NEMA17 23 mm + TM 200** (T8 리드 8, 황동 너트), 절단 옵션, 11/25 도착, 약 2만 원 × 2 + 배송 3,500 (정산 잔액 300원 → 자비). 상품 치수는 Claude가 페이지를 못 읽어 [추측]: 앞 돌기 Φ22 · 앞 나사 M3 간격 31 · 너트 플랜지 Φ22 · 4구멍 PCD 16.

## 3. 최종 수정 목록
1. **주문**: 23 mm + TM 200, 2개, 너트 포함, **절단 X 155 mm / Y 132 mm** (몸 앞면 기준 — X는 판이 23 mm 바깥으로 가서 끝 x 28을 맞추려면 155).
2. **217 X 모터판**: +x 갠트리 레일 **바깥 면**으로 옮김 (모양·구멍 그대로, 뒤집지 않음). 새 Ø3.4 × 4 (31 간격), 위 2개는 레일 쪽 면에 접시. 레일에 M4 둥근머리 × 8 + 2020 M4 T너트 2 (M5 대신). 모터 먼저 판에 → 판을 레일에.
3. **211 Y 모터판 (YM)**: 자리 그대로. 새 Ø3.4 × 4 (31 간격), 기둥 옆 1개는 접시 또는 생략.
4. **XN**: 가운데 Ø8.5 → Ø10.5, M3 탭 2 (Ø2.5, 나사 M3 × 6).
5. **CP**: 가운데 그대로, Ø3.4 × 2 (가로) + 뒤 M3 너트·와셔.
6. **펌웨어 (서현 담당 — 요청만)**: 리드 2 → 8 → 1/4 스텝 **400 → 100 걸음/mm** (1 mm = 25 풀스텝). 원점 찾기 천천히 (Y는 레버 뒤 0.9 mm에서 판이 원점 팔에 닿음 — 지금 설계 그대로). DRV8825 전류 한도를 새 모터 정격에. X 모터 선은 프레임 밖.
7. **안 바뀌는 것**: meviy 판 재주문 없음, 레일·봉·베어링·스위치 위치, Y 모터 위치.
