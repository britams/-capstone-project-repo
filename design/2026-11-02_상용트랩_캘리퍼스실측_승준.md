## 맞춰 본 것 (계산, [가능성 높음])
- 걸쇠 고리 두께 = (85.6 − 81.2)/2 = **2.2**, 포획통 레일 폭 = (93.1 − 85.6)/2 = **3.75**
- 차양막 바깥 고리(바깥 89.6)가 레일에 들어가면 큰 벽과 틈 (93.1 − 89.6)/2 = **1.75**. 이때 바깥 고리 두께는 (89.6 − 85.6)/2 = **2.0 이하**, 안지름 D2i는 **85.6 이상**이어야 함 → D2i 재면 확인
- 토막·빈 구간이 4쌍이라 4(a + b) ≈ 2πR → R ≈ 35.7 (지름 약 71) → 토막 한 개 약 57°, 빈 구간 약 36° (합 93°, 직선·원호 차이) → 토막 바깥지름 약 71~73, c 6.8과 D2i 약 86이면 맞음
- 높이: 차양막 바깥 고리 8.0 > 레일 깊이 6.0~6.7 → 포획통 레일 바닥이 바깥 고리 꼭대기에 얹히고, 걸쇠 고리 끝은 차양막 바닥에서 약 1.3 위, 걸쇠는 약 1.9~4.4 높이 (h3 기준면이 같다는 가정) [추측]
- 잠김: 걸쇠(높이 1.9~4.4)가 빈 구간 b로 내려간 뒤 돌려서 토막 쪽으로 가려면, 토막 바깥면 아래쪽에 걸쇠가 들어갈 가로 홈(파인 곳)이 있어야 함 → 확인 필요 [추측]
- p_in 3.1 → 걸쇠 끝 지름 75.0. 토막 바깥지름 = D2i − 2c = 76.3 (D2i 89.9) 또는 74.6 (D2i 88.2) → 걸쇠 끝이 토막 바깥면에 겨우 닿거나 못 미침 → 토막 위에 걸리는 방식이 아닐 가능성 [추측]. 토막 바깥면의 홈, 토막 끝 계단(턱)에 걸리는지 실물로 확인
- → 처음 사진 어림(바깥 고리 안 83, 토막 바깥 79)은 원근 때문에 틀린 듯. 걸쇠 고리(81.2~85.6)는 차양막 홈 c 안에 들어가고, 걸쇠가 안쪽으로 약 4.6 mm 이상 튀어나와야 토막에 닿음 [추측]
