# 급이 펌프 유량 재는 법 — Kamoer NKP 12 V (2026-11-17, 서현 · Claude CAP-AI-62)

왜: 펌웨어 `PUMP_MAX_MS = 200`과 Pi `feed_pump_ms = 100`은 유량을 **100 mL/min으로 가정**한 값이다 [추측]. 접시 177d는 약 0.34 mL라서, 실제 유량이 이보다 크면 한 번에 접시가 넘치고, 작으면 말벌이 먹을 양이 모자란다. 펌프를 받으면 한 번 재서 두 값을 고친다.

## 1. 준비
- 펌프 + 실리콘 관 (실제로 쓸 길이 그대로 — 관이 길면 유량이 줄어듦 [가능성 높음]), 물컵 2개, 주방 저울 (1 g 단위도 됨, 0.1 g이면 더 좋음). 물 1 g = 1 mL.
- 배선: 회로 11/17 판 그대로 — 12 V → MOSFET V+, 펌프 +·− → Q3 OUT+·OUT− (1N5819도 같이), UNO 2 D6 → Q3 TRIG. UNO 2에 `trap_doors` v0.3.
- 아두이노 IDE 시리얼 모니터: 115200, 줄 끝 '새 줄(NL)'.

## 2. 재기
1. 관 끝을 버리는 컵에 넣고 `PUMP 200`을 물이 끝까지 나올 때까지 여러 번 보냄 (관 채우기). 관 안 공기가 빠져야 값이 맞음.
2. 빈 컵 무게 W0 (g)를 적음. 관 끝을 이 컵에 넣음.
3. `PUMP 200`을 **50번** 보냄. 한 번 보내고 `DONE PUMP 200`이 나온 뒤 다음을 보냄 (모두 10 s).
4. 컵 무게 W1을 적음 → 한 번 양 v₂₀₀ = (W1 − W0) ÷ 50 mL.
5. 같은 방법으로 `PUMP 100` 50번 → v₁₀₀. (짧게 돌리면 처음 도는 동안 덜 나와서 v₁₀₀ < v₂₀₀ ÷ 2일 수 있음 [가능성 높음] — 그래서 둘 다 잼)
6. 1~5를 3번 하고 평균.

| 회 | W0 (g) | W1, PUMP 200 ×50 (g) | v₂₀₀ (mL) | W1, PUMP 100 ×50 (g) | v₁₀₀ (mL) |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 평균 | | | | | |

## 3. 값 고치기
- 유량 Q (mL/ms) ≈ (v₂₀₀ − v₁₀₀) ÷ 100 (처음 도는 손해를 뺀 값), 시작 손해 v₀ ≈ v₁₀₀ − 100 × Q.
- **PUMP_MAX_MS** = (0.30 − v₀) ÷ Q, 10 단위로 내림 — 0.30 mL = 접시 0.34 mL에서 10 % 여유.
- **feed_pump_ms** = (0.20 − v₀) ÷ Q, 10 단위로 반올림 — 한 번 약 0.2 mL (인터페이스 정의서 급이 줄).
- 예: v₁₀₀ = 0.12, v₂₀₀ = 0.27 → Q = 0.0015 (90 mL/min), v₀ = −0.03 → MAX = 220 ms, feed = 150 ms.
