## 0. 결론 먼저
- **[확실 — 코드 대조] 지금 펌웨어 `trap_controller.ino` v0.1은 UNO 1개 기준이다.**
  - 회로는 UNO 2개라서 핀 10개가 다르다: 펜, HX711 2개, 문 서보 3개, 원점 3개(펌웨어에 없음), 빛 게이트·조명·송신·레일 감지(펌웨어에 없음).
  - 이대로 회로에 올리면 다음 일이 생긴다:
    - 펜 서보 신호가 문 서보 자리(A0)로 간다.
    - 원점 스위치 A3에 서보 펄스가 나간다.
- 할 일은 스케치를 둘로 나누는 것이다: **`trap_motion` (UNO 1)**과 **`trap_doors` (UNO 2)**. 명령 형식(한 줄 텍스트, OK/ERR/DONE/EVT)은 그대로 둔다.
- **[확실 — elec_budget worst_cases] 켤 때 전류가 퓨즈를 넘는다.** `setup()`이 서보 4개를 한꺼번에 attach하면 최대 3.27 A로, 본체 퓨즈 3 A를 넘는다. → 하나씩, 0.3 s 간격으로 켠다.

## 1. UNO 1 (`trap_motion`) — 움직임

| 기능 | 지금 펌웨어 | 바꿀 핀 | 메모 |
|---|---|---|---|
| 바닥 F (ULN) | D2~D5 | **같음** | |
| 마커 X | D6~D9 | **같음** | |
| 마커 Y | D10~D13 | **같음** | |
| 펜 서보 PEN | A3 | **A0** | |
| HX711 DT / SCK | A4 / A5 | **A1 / A2** | RATE 다리 → 5 V (80 Hz) |
| 원점 F / X / Y | 없음 | **A3 / A4 / A5** | `INPUT_PULLUP`, 눌리면 LOW, 100 nF |
| 문 서보 IN/CAP/REL | A0/A1/A2 | **UNO 2로 옮김** | |

명령:
- **`HOME <F|X|Y>` 새로 만듦.**
  - 스위치 쪽으로 가다가 LOW가 되면 멈추고, 1 mm 물러났다가 다시 천천히 닿는다.
  - 그 자리를 소프트 한계의 끝(F 0, X −18, Y −40)으로 정한다.
  - 못 찾으면 `ERR HOME <축> NOSWITCH`. 한도는 **축마다 (행정 + 4 mm)** — F 20,634 · X 20,379 · Y 31,587 반걸음 (11/08 고침, CAP-AI-42 V6: 처음 적은 20480은 F 40 mm 기준이라 행정 58 mm인 Y가 +18 mm에서 켜지면 스위치에 못 닿아 거짓 NOSWITCH).
  - 응답: `DONE HOME <축> <걸음수>`.
  - 참고: `bringup/b4_axis/b4_axis.ino`의 `h`.
- `ZERO`는 남긴다 (스위치 고장일 때 손으로 맞추기).
- **`HOLD F` 기본값을 1에서 0으로 바꾸기를 권한다** [가능성 높음 — `elec_budget.py` hold_check].
  - 바닥을 내리려는 토크는 0.64 N·mm이고, 28BYJ-48 기어 마찰은 59~118 N·mm이다 (92배 이상).
  - HOLD 1이면 9시간에 약 3.7 Wh를 버린다. ~~다시 HOLD 1이 필요한 때는 PRESS 중뿐이다.~~ → **PRESS 중에도 필요 없다** (11/08, CAP-AI-42 V7: 누르는 힘 0.5 N의 역구동 토크 0.64 N·mm < 기어 마찰 59~118 N·mm).
- `DOOR`·`SERVO IN|CAP|REL`·`SETDOOR IN|CAP|REL`은 빼서 UNO 2로 옮긴다. `PEN`·`SERVO PEN`은 남긴다.
- 인사말: `EVT READY trap_motion v0.2`.

## 2. UNO 2 (`trap_doors`) — 문·빛 게이트·조명

| 기능 | 핀 | 회로 |
|---|---|---|
| 레일 감지 (비상 정지) | **D2** | +5V_B → 10 kΩ → D2. LOW면 구동 전원이 꺼진 것 |
| 위 링 조명 Q1 | **D3** (PWM) | MOSFET |
| 송신 켜기 Q4 (EMIT_EN) | **D4** | 송신 9개(문 LED 6 + 2167 3)를 한꺼번에 켜고 끔 |
| 아래 조명 Q2 | **D5** (PWM) | MOSFET |
| 통로 게이트 G1 / G4 / G6 | **D7 / D8 / D12** | 2167, 10 kΩ 풀업, 끊기면 LOW |
| 문 서보 IN / CAP / REL | **D9 / D10 / D11** | MG90S |
| 문 빔 G2 / G2b / G3 / G3b / G5 / G5b | **A0 / A1 / A2 / A3 / A4 / A5** | 포토TR 이미터 팔로어, `analogRead`, 빛 받으면 높음 |
| 예비 | D6, D13 | |

명령 (제안):
- **`SELFTEST`**: 켤 때 한 번 자동으로 하고, 명령으로도 한다.
  - 송신을 끄고 켜며 9쌍을 잰다.
  - 문 빔: 문턱값 = (켬 + 끔)/2. 차이가 200보다 작으면 그 빔은 FAIL.
  - 2167: 끔 = LOW, 켬 = HIGH여야 OK.
  - 응답: `OK SELFTEST G1=OK G2=OK ... G2b=FAIL(87)`.
  - 하나라도 FAIL이면 그 문의 `DOOR CLOSE`를 거부한다 → `ERR DOOR <이름> BEAMFAIL`.
- **`GATES`**: `OK GATES G1=1 G2=1 ...` (1 = 빔 이어짐 / 0 = 끊김).
- **`EVT GATE <이름> BLOCK|CLEAR`**: 바뀔 때마다 보낸다. 같은 값이 20 ms 이어진 뒤에만 보낸다 (잡음 거르기). **G1 BLOCK이 진입 신호다.**
- **`DOOR <IN|CAP|REL> CLOSE` 안전 규칙** (`bringup/b3_door/b3_door.ino`와 같음):
  1. 그 문의 빔 2개가 0.2 s 동안 계속 이어져야 닫기 시작한다. 그전에는 기다리고, 2 s가 넘으면 `ERR DOOR <이름> WAIT`.
  2. 닫는 동안 빔이 끊기면 바로 연다 → `EVT DOOR <이름> REOPEN <n>`.
  3. 3번 실패하면 `EVT DOOR <이름> BLOCKED`. 열어 둔 채 Pi가 판단한다.
  4. 다 닫히면 `DONE DOOR <이름> CLOSED`.
- `DOOR … OPEN`, `SERVO`, `SETDOOR`는 지금 펌웨어와 같다.
- **`LIGHT <TOP|BOT> <0~255>`** → Q1 / Q2 PWM.
- **`EMIT <0|1>`**: 송신 켬/끔. 기본은 켬. 밤 모드에서는 꺼도 된다.
- **`RAIL`** → `OK RAIL 1|0`. 바뀌면 `EVT RAIL 0` (비상 정지 눌림).
  - RAIL 0이면 문 명령을 거부한다 → `ERR RAIL`.
  - 다시 1이 되면 `EVT RAIL 1`. Pi가 HOME부터 다시 한다.
- 인사말: `EVT READY trap_doors v0.2`.

## 3. Pi (`control/pi/trap_link.py`)
- 포트가 2개다. `/dev/ttyACM0`·`ACM1` 순서는 켤 때마다 바뀔 수 있다 [가능성 높음]. 그래서 **`EVT READY` 이름(trap_motion / trap_doors)으로 어느 쪽인지 정한다.**
- 켜는 순서:
  1. 두 UNO의 READY를 받는다.
  2. UNO 2에 `SELFTEST`와 `RAIL`을 보낸다.
  3. UNO 1에 `HOME F`, `HOME X`, `HOME Y`를 보낸다.
  4. 대기로 간다.
- 서보는 한 번에 하나만 움직인다 (규칙 최대 1.8 A). 문 명령과 `PEN` 명령이 같은 순간에 나가지 않게 Pi가 순서를 정한다.
