## 1. 배치 — 상용 트랩 어디에 끼우나

```
        ┌───────────────┐
        │ 상용 포획통   │  ← 격리함으로 그대로 사용 (F5-2)
        └──────┬────────┘
        ┌──────┴────────┐ 104 상부 결합부
        │   모듈 100     │ ─────→ 174 방생 출구 (트랩 밖으로, 한 방향)
        └──────┬────────┘ 102 하부 결합부
   ════════════╧═════════════  상용 트랩 차양막(지붕)
        상용 트랩 몸통 (유인제·포획구) — 갇힌 말벌이 빛 쪽(위)으로 올라옴
```

- [가능성 높음] **상용 포획통을 격리함으로 쓴다.** 방제 모드의 "전부 가둠"과 조사 모드의 여왕벌·다른 종 격리가 모두 "포획통으로 올려 보냄" 하나로 해결된다. 원래 상용 트랩의 동작과 같아서, 모듈이 고장 나면 문을 포획통 쪽으로 열어 두는 것만으로 일반 트랩이 된다 (D2 환류 2 '고장 시 가둠').
- 방생 출구 174만 트랩 밖으로 따로 낸다 (D2 환류 1).

## 3. 작동 순서 (조사 모드, 표식 없는 등검은말벌 일벌)

1. **대기**: 입구 문 112 열림, 바닥 140 내려감, 마커 160은 캡 166 안, 분기 문 170은 포획통 쪽 닫힘·방생 쪽 닫힘
2. **진입**: 말벌 H가 빛 쪽으로 올라와 입구 110 통과 → 센서 114 감지 → 입구 문 112 닫힘
3. **판별**: 카메라 180이 종·계급·표식·마리 수 판단 → 로그. 여왕벌·다른 종·불확실·두 마리 → 9로
4. **자세 고정**: 바닥 140이 올라가 H의 등을 격자망 130에 붙임. 힘은 스프링 146·하중 센서 148로 상한 이하. 카메라가 흉부가 격자 쪽인지 확인 → 아니면 바닥을 내렸다 다시 올림
5. **마킹**: 마커 160이 캡에서 나와 흉부 위로 → 구동부 164가 격자 눈 사이로 팁을 내림 → 점 → 마커는 캡으로 복귀
6. **확인**: 카메라가 점 확인 (실패 시 4~5 한 번 더)
7. **급이**: 바닥을 조금 내려 고정을 풀고, 급이구 142에서 먹게 둠 (시간 ≥ 마커 건조 시간)
8. **방생**: 분기 문 170을 방생 쪽으로 → H가 방생 출구 174로 나감 → 문 닫힘 → 1로
9. **격리** (방제 모드는 2 다음 바로 여기): 분기 문 170을 포획통 쪽으로 → H가 빛 쪽(위) 포획통으로 올라감 → 1로

## 4. 이 단계에서 드러난 것 (환류)

| 번호 | 발견 | 반영할 곳 |
|---|---|---|
| 1 | [가능성 높음] **격자망은 판별 정확도에도 쓸 수 있다.** 말벌이 격자에 붙으면 카메라–흉부 거리가 일정하고, 격자 눈이 크기 기준(자)이 된다 → 흉부 폭을 사진으로 잴 수 있음 = 여왕벌 판별을 카메라로 하는 근거 (승준 SJ-02의 '카메라냐 기구냐' 질문에 대한 답 후보) | 인터페이스 정의서, D6 |
| 2 | [추측] 흉부 폭 경계 차이가 약 0.1 mm라, 사진으로 가르려면 측정 오차가 ±0.05 mm 수준이어야 함 → 카메라 해상도·초점 거리 요구 (승준 확인) | 인터페이스 정의서 |
| 3 | 카메라 180과 마커 160이 둘 다 격자 위에 있음 → 마커가 시야를 가림. 마커가 찍을 때만 들어왔다 빠지는 구조, 또는 카메라를 비스듬히 | D6, 인터페이스 |
| 4 | 방생 때 말벌이 출구 쪽으로 가게 하는 방법 필요 — 빛 쪽으로 가는 습성 이용 (출구 쪽 밝게, 포획통 쪽 어둡게) [추측] | 조명 182, 시험 |
| 5 | 격리할 때는 반대로 포획통 쪽이 밝아야 함 → 조명 또는 가림막 전환 | 조명 182 |
