# VespAI 점검 키트 (서현, 2026-11-02, CAP-AI-21)

승준 웹캠 시험(10/29)에서 VespAI가 잘 못 잡은 원인을 우리 장치 조건으로 나눠 확인하는 키트다. 판단 근거는 `design/2026-11-02_VespAI_점검_서현.md`에 있다.

## 순서 (서현 PC)
1. **`1_install_vespai.bat` 더블클릭** — 승준 J1 설치 스크립트로 `문서\capstone_vespai`에 VespAI·YOLOv5·가중치를 깐다 (처음 5~15분, 약 300 MB).
   - "Python not found"가 나오면 python.org에서 **Python 3.12**를 깔고("Add python.exe to PATH" 체크) 다시 실행한다.
   - 끝나면 J1 예시 결과(`summary.txt`)도 나온다. 승준 결과(16/21장 일치)와 비슷하면 설치가 정상이다.
2. **`2_webcam_check.bat` 더블클릭** — 웹캠 화면에 VespAI 박스가 뜬다. 영상 창을 한 번 클릭하고 키를 누른다.

   | 키 | 하는 일 |
   |---|---|
   | g | 격자판(구멍 Ø3, 피치 4.4)을 화면에 겹침 — 카메라가 격자 너머로 보는 상태 |
   | k | 마킹실(40 × 40 mm)만 잘라서 넣음 |
   | i | 입력 크기 640 ↔ 1280 |
   | [ ] | 화면 가로가 몇 mm인지 (기본 280, 웹캠에서 약 20 cm) — 말벌 몸길이가 격자 구멍 6칸쯤 되게 맞춘다 |
   | + / − | 표시 신뢰도 |
   | s / q | 사진 저장 / 끝 |
3. (선택) **`3_drop_video_or_folder_here.bat`에 영상 파일이나 사진 폴더를 끌어다 놓기** — 조건 5개(전체, 전체+격자, 마킹실만, 마킹실만+격자, 전체 1280)를 자동으로 돌려 표(`check_summary.txt`)를 만든다. 승준 녹화 원본 영상(`rec_*_raw.mp4`)을 넣으면 같은 장면으로 비교된다.

## 시험 방법 (웹캠, 10~15분)
- 말벌 사진을 **실물 크기(몸길이 25~30 mm)로 인쇄**해서 흰 종이 위에 놓고, 웹캠에서 **약 20 cm**에 둔다. 이게 우리 카메라 조건(격자에서 200 mm, 말벌이 화면 폭의 약 10 %)과 비슷하다.
- 같은 자세로 네 조건을 각 30초씩 본다: ① 그대로 ② g(격자) ③ k(마킹실만) ④ g + k. 끝나면 `out_check_날짜\check_summary.txt`에 조건별 "잡힌 비율"이 나온다.
- 사람 손·얼굴은 화면에서 빼고 한다 (승준 시험의 오검출 60 %는 손·옷·커튼).
- 인터넷 사진·영상은 저작권 때문에 레포에 올리지 않는다. `check_summary.txt`와 `check_*.csv`만 올린다.

## 볼 것
- 격자를 겹치면 잡힌 비율이 얼마나 떨어지나 → 많이 떨어지면 **격자판을 투명(아크릴·PETG)으로** 바꾸는 근거가 된다
- 마킹실만 잘라 넣으면 떨어지나 → 종 판별은 넓은 화면으로, 흉부 위치만 잘라서
- 1280이 640보다 나은가
