## 3. 참고 상용 트랩 분석 — 야생 말벌 포획기

출처: 제품 상자 스캔 3장, 실물 사진 9장 (서현 PC `capstone design_이서현\지금가지고 있는 물품\`)

| 항목 | 내용 | 우리 설계에 주는 의미 |
|---|---|---|
| 크기 | 26 × 26 × 40 cm | 전체 크기 기준선 |
| 구조 (아래→위) | 액체 유인액 통(갈색) → 고체 유인제 망(초록 격자) → 몸통 + 말벌 포획구(노란 깔때기, 실리콘 포획술, 2곳) → 차양막(초록 지붕) → 포획통(투명 구형, 바닥 실리콘 포획술, 옆면 꿀벌 탈출망 슬롯) → 실리콘 뚜껑·손잡이 | 유인·진입·꿀벌 분리·비 가림이 이미 해결된 구조 |
| 핵심 원리 | 빛의 광도차를 인식하는 말벌의 습성 → 들어온 말벌이 밝은 위쪽 포획통으로 올라감 | 말벌이 **스스로 위로 올라가는 경로**가 있음 → 그 경로에 장치를 넣을 수 있음 [가능성 높음] |
| 꿀벌 분리 | 꿀벌은 포획통 위쪽 슬롯으로 바로 탈출 | 비표적 곤충 피해(O3-2) 해결 방식 참고 |
| 분리 방식 | 몸통을 돌려서 분리 (트위스트 결합) | 결합 방식 참고 |
| 설치 | 벌통에서 80~120 cm, 산 쪽(말벌이 오는 방향). 포획구 높이 지면에서 20~25 cm. 포획구 방향은 벌 드나드는 길목과 평행 | 바닥 설치(C1)와 같음. 포획구 높이 = 설계 치수 |
| 전도 방지 | 유인액 통에 자갈을 채워 바람에 넘어지지 않게 함 | **전도 계산(S4)이 실제로 필요한 문제**라는 근거 |
| 운용 | 새벽 4:30~8:00에 흑등(등검은)말벌이 많이 잡힘. 매일 저녁 유인액 보충 | 카메라 조명·전원 운용 시간대, 먹이 보충 주기 |
| 말벌 처리 | 포획통을 냉동실에 약 5분 → 기절 | 표본 채집 방법, 저온 마취 가능성 |
| 지식재산 | 특허 제10-1799771호, 제10-1845239호, PCT/KR2016/011319 | 구조를 그대로 복제한 제품은 문제될 수 있음. 결합형 추가 모듈은 청구항 확인 필요 [추측] |

## 4. 먼저 정할 큰 선택 — 상용 트랩에 얹는 모듈 vs 새 트랩

| | (가) 상용 트랩 추가 모듈 (레트로핏) | (나) 새 트랩 일체형 |
|---|---|---|
| 개념 | 차양막과 포획통 사이(말벌이 위로 올라가는 길)에 마킹 모듈을 끼움 | 유인·진입·마킹·격리를 모두 새로 설계 |
| 장점 | 유인·진입·꿀벌 분리는 검증된 제품에 맡기고 마킹(차별점)에 집중. 양봉농가가 이미 가진 트랩에 붙이는 제품 → 상업성 설명 쉬움. 보유 트랩으로 바로 시험 | 치수·배치를 자유롭게 정함. 특허 문제 없음 |
| 단점 | 상용 트랩 치수에 묶임. 특허 청구항 확인 필요. 포획통 위로 올라가는 말벌은 먹이가 없음 → 먹는 동안 마킹하려면 모듈에 급이구 필요 | 유인·진입을 다시 검증해야 함 (살아 있는 말벌 없이 검증 어려움). 작업량 증가 |
| 판단 | [가능성 높음] 2인·1년·표본만 있는 조건에서는 (가)가 유리 | |

**결정 (2026-10-28, 서현): (가) 상용 트랩 추가 모듈(레트로핏)로 간다.** (CAP-AI-04)
- 따라오는 확인 사항: ① 특허 제10-1799771호·제10-1845239호 청구항과 겹치는지 (KIPRIS에서 확인) ② 모듈이 끼워질 자리(차양막 구멍·포획통 바닥 결합부) 실측 ③ 포획통으로 올라가는 경로에 먹이가 없으므로, 먹는 동안 마킹하려면 모듈에 급이구가 필요한지 D3에서 판단

## 5. 설계 절차 — 이렇게 진행한다

10/26에 문제가 생긴 원인 [가능성 높음]: 대안 비교 없이 스케치 → CAD로 바로 가서, 그려 본 뒤에야 "말벌 위치를 모른다·구동기 7개" 같은 문제가 드러남. 이번에는 **기능별 대안을 먼저 비교하고 고른 뒤** 그린다.
