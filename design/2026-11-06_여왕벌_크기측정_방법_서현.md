# 여왕벌 크기 재는 방법 — YOLO 다음 단계로 '자로 잰다'

정리: 2026-11-06 · 이서현 (Claude, **CAP-AI-25**, 서현 지적 "YOLO는 개체를 파악하는 것이지 크기를 파악하는 도구가 아니잖아")
기준값: 중순판 폭(날개 뿌리 사이, mesoscutum width) **≥ 4.4 mm → 여왕벌 → 격리**. 근거는 `design/2026-11-06_제어알고리즘_판단_서현.md` 8장 (Pérez-de-Heredia 외 2017).
담당: 방법·판단 규칙은 서현(이 문서). 모델 학습·Pi 코드는 승준 `vision/`·`control/`이라 Issue로 제안한다.

## 0. 결론 먼저

- **[확실] 서현 지적이 맞다.** YOLO 상자 크기로는 못 잰다.
  1. VespAI처럼 640 × 640으로 줄여 넣으면, 격자 위 200 mm 시야(약 260 mm 폭)는 **약 2.5 화소/mm**가 된다. 4.5 mm는 11화소뿐이다.
  2. 상자는 날개·다리·배 늘어남까지 감싸서 몸 크기와 1:1로 맞지 않는다.
  3. 등이 격자에서 얼마나 떨어져 있는지 모르면 배율도 모른다.
- **방법: "찾기는 YOLO, 재기는 따로"** (2단계)
  1. 바닥이 말벌을 격자에 붙인 순간(PRESS, 로드셀 F_p)에 찍는다. 이때 등이 **격자 아랫면에 닿아 있어 거리가 정해진다** [확실 — 구조].
  2. 같은 사진 속 **격자 눈 간격 4.4 mm를 자로 쓴다.** 사진마다 배율을 스스로 맞추므로 카메라 높이·초점이 조금 바뀌어도 된다.
  3. YOLO 상자 둘레를 **원본 해상도(4056 × 3040, 15.6 화소/mm)** 에서 잘라낸다. 그 안에서 **키포인트 모델**이 양쪽 날개 뿌리(견판, tegula) 두 점을 찾는다 → 두 점 거리 ÷ 배율 = 중순판 폭.
  4. 사진 5장의 중앙값을 쓴다. ≥ 4.4 mm면 여왕벌.
- **[확실 — 계산] 측정 오차 σ ≤ 0.10 mm여야 신여왕을 98 % 이상 잡는다.**
  - 논문의 신여왕 최소 4.61 mm 기준으로 놓칠 확률이 1.8 %다.
  - 15.6 화소/mm에서 0.10 mm = 1.6화소다.
  - 키포인트 오차가 1~3화소[추측]라 **될 수도 안 될 수도 있다** → 승준 표본 7마리로 J 시험에서 확인한다.
- 재지 못할 때(격자 막대에 가림, 키포인트 신뢰도 낮음)는 **계절 규칙** (서현 결정, 6장).

## 1. 왜 PRESS 때 재나

| 때 | 등과 카메라 거리 | 배율 | 판정 |
|---|---|---|---|
| 들어와서 걸어 다닐 때 (IDENTIFY) | 모름 (바닥 위치 + 말벌 높이) | 모름 | ✗ |
| **눌려서 격자에 붙었을 때 (PRESS 뒤)** | **격자 아랫면 = 고정** | **격자 눈금으로 앎** | ✓ |

- 격자 윗면(눈금이 보이는 면)과 말벌 등(격자 아랫면)은 격자 두께 1.5 mm만큼 차이 난다. 카메라 거리 200 mm에서 배율 차이는 0.75 %이고, 식으로 보정한다: × 200 / 201.5 [확실 — 기하].
- 눌린 말벌은 움직이지 않는다 → 여러 장을 찍어 흔들림 오차를 줄인다.
- 순서표에서 POSE(등이 위인지 확인)와 같은 사진을 쓰므로 **시간이 더 들지 않는다.**

## 2. 배율: 격자를 자로 쓰기
1. YOLO 상자 둘레 ±10 mm를 원본 해상도로 잘라낸다.
2. 격자 막대는 4.4 mm마다 되풀이되는 무늬라, 2차원 푸리에 변환(FFT) 또는 자기상관의 가장 센 주기 = 4.4 mm ↔ 화소 수.
3. mm/화소 = 4.4 / 주기(화소) × (200 / 201.5).
4. 렌즈 왜곡은 처음에 한 번 체커보드로 보정(OpenCV `calibrateCamera`)한다 [확실 — 일반 방법]. 격자 가운데 40 mm 안이라 왜곡이 작다 [가능성 높음].

## 3. 재기: 키포인트 두 점
- **모델:** YOLO 포즈(키포인트) 모델에 점 4개 — 왼·오른 견판, 머리 앞, 허리(배자루).
  - 견판 두 점 → 중순판 폭.
  - 머리–허리 → 몸 방향 (폭을 몸 방향에 수직으로 쟀는지 확인).
- **어디서 돌리나:** 잘라낸 원본 해상도 조각(약 300 × 300 화소)이라 Pi 5 + AI HAT+(Hailo)에서 돌린다 [가능성 높음 — 승준 확인]. IMX500 카메라 안의 모델은 찾기(1단계)만 한다.
- **학습 자료:** 승준 표본 7마리 + 현장 사진에 견판 두 점을 찍어(라벨) 학습. 표본은 캘리퍼로 잰 실제 폭이 있어 정답을 안다.
- **예비 방법 (학습 없이):** 등검은말벌 가슴은 어두운 색이다. 상자 안에서 어두운 덩어리의 윤곽에 타원을 맞춘다. 이때 **격자 막대에 가린 부분은 빼고** 보이는 가장자리만 쓴다. 격자가 열린 면적은 (3.0/4.4)² ≈ 46 %다. 몸 방향에 수직인 최대 폭 = 중순판 폭 근사. 키포인트와 다르면 '못 잼'으로 둔다.

## 4. 판정 규칙
1. PRESS 뒤 0.5 s 간격으로 5장
2. 장마다: 배율, 견판 두 점(신뢰도 ≥ 0.6), 폭
3. 3장 이상 유효 → **중앙값 ≥ 4.4 mm → 여왕벌 → 격리** / < 4.4 mm → 일벌 → 찍기
4. 유효 < 3장 → 바닥을 2 mm 내렸다 다시 눌러 한 번 더 (말벌이 조금 움직여 가림이 바뀜) → 그래도 안 되면 6장 규칙
5. 기록: 폭, 배율, 유효 장수, 몸 높이(4장 끝), 무게(5장) → 나중에 기준을 고치는 자료

**오차별 결과** [확실 — 정규분포 계산, σ는 측정 시험으로 정함]:

| 측정 σ | 신여왕 4.61 mm 놓침 | 창업 여왕 4.48 mm 놓침 | 가장 큰 일벌 4.49 mm 격리 | 보통 일벌 4.2 mm 격리 |
|---|---|---|---|---|
| 0.064 mm (1화소) | 0.05 % | 11 % | 92 % | 0.1 % |
| **0.10 mm** | **1.8 %** | 21 % | 82 % | 2.3 % |
| 0.15 mm | 8.1 % | 30 % | 73 % | 9.1 % |
| 0.20 mm | 15 % | 35 % | 67 % | 16 % |

- 논문에서도 4.48 mm인 여왕(둥지 6)이 있었다. 크기만으로는 이런 여왕을 다 잡지 못한다 [확실 — 논문]. → 6장 계절 규칙이 보완한다.

## 5. 카메라 말고 같이 기록할 것 (판단에는 아직 안 씀)
- **몸 높이:** 바닥이 처음 닿은 순간(로드셀 > 0.02 N)의 바닥 위치 → h = 격자 아랫면 − 바닥 윗면. 스텝 수로 0.002 mm 단위 [확실 — 리드 8 mm ÷ 4096]. 여왕/일벌 높이 기준은 문헌에 없음 → 기록만.
- **무게:** 누르기 전 말벌이 바닥에 서 있을 때 로드셀 값 − 0점. 논문 젖은 무게 기준은 0.618 g(가르는 힘 77 %, 폭보다 약함). 1 kg 로드셀 + HX711의 흔들림은 약 0.05~0.1 g [추측] → 기록만.

## 7. 시험 (J7 제안)
1. 승준 표본 7마리: 캘리퍼로 중순판 폭(±0.02 mm) → 정답
2. 표본을 격자 아래 바닥에 놓고 바닥을 올려 붙임 → 5장 × 위치 5곳(가운데·모서리) × 7마리 → 카메라 폭
3. 오차 σ 계산 → **σ ≤ 0.10 mm면 통과**
4. 실패하면 둘 중 하나:
   - 카메라를 가까이(접사 렌즈 +4 디옵터면 초점 약 11 cm, 약 28 화소/mm [추측])
   - 기준을 4.3 mm로 낮춤 (일벌 격리가 늘어남)

## 8. 순서표에 바뀌는 것
