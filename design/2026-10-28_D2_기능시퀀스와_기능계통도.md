## 1. 기능 시퀀스 — 말벌 한 마리 기준

```
[상용 트랩 몸통] 갇힌 말벌이 빛 쪽(위)으로 올라옴
        │
   ① 진입 허용 ── 입구 크기로 1차 거름 (장수말벌 대부분은 못 들어옴 → 상용 트랩에 남음)
        │
   ② 한 마리 분리 ── 뒤를 막아 추가 진입 차단
        │
   ③ 촬영·판별 ── 종 / 계급(여왕벌·일벌) / 표식 유무 → 로그 (두 모드 모두)
        │
   ┌────┴──────────────── 방제 모드 ──→ ⑦ 격리 (전부)
   │ 조사 모드
   ├─ 등검은말벌 여왕벌 ──────────────→ ⑦ 격리
   ├─ 판별 불확실 ────────────────────→ ⑦ 격리 (여왕벌을 놓치지 않는 쪽)
   ├─ 다른 종 (입구를 통과한 것) ──────→ ? (3장 Q5)
   ├─ 등검은말벌 일벌, 표식 없음 → ④ 자세 고정 → ⑤ 마킹 → 표식 확인(실패 시 1회 재시도) → ⑥ 급이 → ⑧ 방생
   └─ 등검은말벌 일벌, 표식 있음 ─────────────────────────────────────→ ⑥ 급이 → ⑧ 방생
        │
   ⑨ 초기화 ── 다음 개체 대기
```

| 단계 | 하는 일 | 끝나는 조건 | 관련 요구사항 |
|---|---|---|---|
| ① 진입 허용 | 모듈 입구를 열어 둠, 크기로 거름 | 진입 감지 | — |
| ② 한 마리 분리 | 뒤를 막음 | 한 마리만 안에 있음 확인 | — |
| ③ 촬영·판별 | 종·계급·표식 판별, 사진·시각 기록 | 분류 결과 나옴 | R1, R2, R5, R8 |
| ④ 자세 고정 | 흉부 등쪽이 정해진 위치에 오게 함 | 흉부 위치 확인 | R7 |
| ⑤ 마킹 | 흉부에 한 색 점 | 카메라로 점 확인 | R3, R4 |
| ⑥ 급이 | 정해진 시간 동안 먹이 | 시간 ≥ 마커 건조 시간 | R4, R6 |
| ⑦ 격리 | 격리함으로 보냄, 못 나오게 | 격리함 진입 확인 | — |
| ⑧ 방생 | 트랩 **밖으로** 내보냄 | 출구 통과 확인 | R6 |
| ⑨ 초기화 | 문·마커 대기 위치 | — | — |

## 2. 기능계통도 (갱신)

| 1차 기능 | 2차 기능 | 10/11판 대비 |
|---|---|---|
| (1) 진입·분리 | F1-1 크기로 거름 · F1-2 한 마리씩 들임 · F1-3 처리 중 추가 진입 차단 | 유인(구 F1-1)은 상용 트랩이 맡아 삭제, 크기 거름 신규 |
| (2) 감지·판별 | F2-1 진입 감지 · F2-2 종 판별 · F2-3 계급 판별 · F2-4 표식 유무 판별 · F2-5 마킹 성공 확인 | F2-5 신규 |
| (3) 마킹 | F3-1 자세 고정 · F3-2 고정 힘 제한 · F3-3 흉부 도포 · F3-4 마커 마름 방지 | 구 F4-1·4-2를 마킹 쪽으로 옮김 |
| (4) 급이 | F4-1 먹이 저장 · F4-2 정해진 시간 먹이 공급 | 순서가 마킹 뒤로 |
| (5) 배출·분기 | F5-1 격리함으로 보냄 · F5-2 격리 보관 · F5-3 트랩 밖으로 방생 | 방생 경로를 '밖으로'로 명확히 |
| (6) 데이터 | F6-1 로그(사진·시각·종·계급·표식) · F6-2 원격 전송 · F6-3 이상 알림 | 두 모드 공통 |
| (7) 운용·전원 | F7-1 모드 전환 · F7-2 전력 공급 · F7-3 대기 전력 절감 | 모드 전환 신규 |
| (8) 결합·구조 | F8-1 상용 트랩에 결합·탈착 · F8-2 비·바람 견딤 | 신규 (S1 환류 '구조 지지' 반영) |

꿀벌 등 비표적 곤충 분리는 상용 트랩 탈출망이 맡는다 (구 F4-4 중 비표적 부분 삭제).

## 3. 이 단계에서 드러난 것 (환류)

| 번호 | 발견 | 반영할 곳 |
|---|---|---|
| 1 | [확실] **방생 출구가 따로 필요하다.** 레트로핏 모듈은 상용 트랩 안쪽에 있어서, 방생한 말벌이 트랩 밖으로 나갈 경로가 없으면 다시 갇히거나 포획통으로 간다. 그 출구로 바깥 말벌이 들어오면 안 된다 (한 방향) | F5-3, D3 |
| 2 | [가능성 높음] **고장·정전 시 기본 동작을 '가둠'으로** 하면, 모듈이 멈춰도 상용 트랩처럼 동작한다 (말벌이 풀려나지 않음) | F7, 문 구동 방식 선정 |
| 3 | [추측] 새벽 몰림: 한 마리 3분이면 시간당 20마리. 한 트랩에 아침마다 몇 마리 오는지 자료 없음 → 대기 말벌은 상용 트랩 몸통에서 기다리므로 막히지는 않지만 처리량 한계는 확인 필요 | R6, 시험 계획 |
| 4 | 두 마리가 동시에 들어오는 경우 → ② 실패 처리 필요 (둘 다 격리 / 하나 돌려보냄) | F1-2, 제어 순서 |
| 5 | 격리함이 차는 경우 → 이상 알림 | F6-3 |
