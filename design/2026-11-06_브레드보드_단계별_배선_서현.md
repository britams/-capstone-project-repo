# 브레드보드 단계별 배선 — 하나씩 꽂고, 하나씩 확인

정리: 2026-11-06 21시 · 이서현 (Claude, **CAP-AI-33**, 제어·회로 위임). 도면(D5g)과 상관없이 지금 할 수 있는 '회로 논리' 시험.

**바탕**
- 핀: `design/2026-11-06_회로설계_서현.md`
- 선 번호: `design/2026-11-06_하네스표_서현.md` (P·S·M·V·G·L 번호)
- 시험 스케치: `design/circuit/bringup/` (회로 시험용 — 펌웨어는 승준 `control/firmware/`)

> **[확실] 스케치 4개는 이 환경에서 컴파일하지 못했다** (아두이노 컴파일러 설치가 막힘). 처음 올릴 때 Arduino IDE에서 '확인(✓)'부터 누르고, 오류가 나면 Issue #7이나 이 문서에 적는다.

## 0. 쉬운 설명 (초등학생용)
- **브레드보드**는 구멍이 줄줄이 뚫린 판이에요. 납땜 없이 선을 꽂았다 뺐다 할 수 있어요. 같은 줄 구멍끼리는 속에서 이어져 있어요.
- 레고처럼 **한 번에 한 칸씩** 쌓아요. 한 단계를 꽂으면 바로 확인하고, 잘 되면 다음 단계로 가요. 한꺼번에 다 꽂으면 안 될 때 어디가 틀렸는지 못 찾아요.
- 단계마다 **"이렇게 되면 통과"** 가 정해져 있어요. 통과 못 하면 다음 단계로 가지 않아요.

## 1단계 — 힘 전기 길만 (아두이노 없음)
| 꽂을 것 | 선 번호 |
|---|---|
| 5 V 3 A 어댑터 → DC 잭 → 퓨즈 → 비상 정지 → 와고 +5V 묶음 | P01, P03, P04 |
| DC 잭 − → 와고 GND 묶음 | P02 |

**확인 (테스터)**
1. 와고 +5V ↔ GND: **4.75~5.25 V**
2. 비상 정지를 누르면: **0 V**. 다시 돌려 풀면 5 V
3. 극성: 빨강이 +인지 (테스터가 −5 V를 보이면 잭 선을 바꿈)

**통과 못 하면:** 퓨즈가 끊겼는지, 비상 정지가 NC(평소 붙음)인지 확인한다. NO를 샀으면 단자를 바꾼다.

## 2단계 — UNO 2 + 빛 게이트 1쌍 (자가 시험)
| 꽂을 것 | 선 번호 / 핀 |
|---|---|
| 와고 → 게이트 허브(브레드보드 한쪽 줄) +5V·GND | P08 |
| 수신 흰 선 + **10 kΩ 풀업(+5V)** → UNO 2 **A0** | S11 (G1) |
| 송신 검정 → MOSFET(또는 릴레이) → GND, 켜기 신호 ← UNO 2 **D4** | S11 (EMIT_EN) |
| +5V_B → 10 kΩ → UNO 2 **D2** (레일 감지) | P11 |
| UNO 2 GND → 와고 GND (**꼭**) | P10 |
| UNO 2 USB → PC (나중에 Pi) | — |

**스케치:** `bringup/b2_gate/b2_gate.ino`

**확인 (시리얼 모니터 115200)**
1. 손으로 빛을 가리면 `BLOCK`, 떼면 `CLEAR`
2. `s` 입력 → `SELFTEST off=OK on=OK`
3. 비상 정지를 누르면 `RAIL=0`, 풀면 `RAIL=1`

**MOSFET이 아직 없으면:** 보유 릴레이 모듈로 송신 GND를 끊는다. 자가 시험 1회는 할 수 있다 (딸깍 소리).

## 3단계 — 문 서보 1개 + 문 빔 2개 (끼임 방지 규칙)
| 꽂을 것 | 선 번호 / 핀 |
|---|---|
| 와고 → 서보 허브 +5V·GND, 허브에 **1000 µF** (+ 다리를 +5V로) | P07 |
| 입구 문 서보 → 허브 S2, 신호 ← UNO 2 **D9** | V02, S10 |
| G2 → **A1**, G2b → **A2** (각 10 kΩ 풀업) | G02, G03 |

**스케치:** `bringup/b3_door/b3_door.ino`
- 열림·닫힘 각도 `ANG_OPEN`·`ANG_CLOSED`는 실물에서 맞춘다.

**확인**
1. `c` → `CLOSED`
2. 빔을 손으로 막은 채 `c` → `WAIT`가 계속 나오고 **문이 안 움직임**
3. 닫는 중에 빔을 끊으면 → `REOPEN try=1` (바로 다시 열림)
4. 계속 막고 있으면 3번 뒤 `BLOCKED`
5. (가능하면) 테스터를 전류로 놓고 서보 선에 끼워 움직일 때 전류를 본다 → 0.7 A 안팎 [가능성 높음]

## 4단계 — UNO 1 + 바닥 축 (원점)
| 꽂을 것 | 선 번호 / 핀 |
|---|---|
| 와고 → ULN2003 F 전원 | P04 |
| UNO 1 **D2~D5** → ULN F IN1~IN4 | S01 |
| ULN F → 바닥 모터 (모터에 달린 5핀 그대로) | M01 |
| 원점 F: **A3** ↔ 스위치 NO, COM → GND, 100 nF 병렬 | S07 |
| UNO 1 GND → 와고 GND | P10 |

**스케치:** `bringup/b4_axis/b4_axis.ino`

**확인**
1. `u` → 모터가 한 방향으로 돎. `d` → 반대로 돎
2. `h` → 내려가다 스위치를 누르면 멈추고 `HOME OK 걸음수`. **손으로 스위치를 눌러도 멈춰야 함**
3. 멈춘 뒤 모터·ULN이 뜨겁지 않음 (코일 끔 — HOLD F 0)
4. 방향이 반대면 → 스케치의 `stepOnce(-1)`·`(+1)`을 서로 바꿈 (선을 다시 꽂지 않음)

이렇게 되면 X·Y 축도 같은 방법으로 한다: S02·M02·S08 (D6~D9, A4), S03·M03·S09 (D10~D13, A5).

## 5단계 — 로드셀 + 전부 연결
| 꽂을 것 | 선 번호 / 핀 |
|---|---|
| UNO 1 5V·GND·**A1**(DT)·**A2**(SCK) → HX711 | S05 |
| HX711 E+·E−·A−·A+ → 로드셀 빨강·검정·흰색·초록 | S06 |
| HX711 RATE 다리 → 5V (80 Hz) | — |

**스케치:** `bringup/b5_loadcell/b5_loadcell.ino`

**확인**
1. `t`(0점) → `g=0.00` 근처
2. 100 g 추를 올리고 `k` → 이후 g로 나옴, `sd` **0.1 g 이하** [가능성 높음 — 목표]
3. 무게를 올렸는데 숫자가 줄면 A+·A−를 바꿈

**전부 연결 (마지막):**
- 3단계 서보 3개, 4단계 축 3개, 펜 서보, 조명 MOSFET을 모두 꽂는다.
- 이 단계는 승준 펌웨어로 켠다.
- 테스터를 와고 입력에 전류 모드로 끼우고 확인한다:
  - 켤 때 **1.9 A 아래** — 서보는 한 번에 하나씩 (전기계통 문서 peak 1.86 A)
  - 퓨즈가 안 끊어짐
