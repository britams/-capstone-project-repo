### ME1 동력나사의 올림·내림 토크와 자립 — 기계요소설계 (M1 연결)
③ 교과서 유제 연계
| 항목 | 내용 |
|---|---|
| 교재명 | Wright, *Design and Analysis of Machine Elements* (DANotes, University of Western Australia) — Threaded fasteners: Tutorial problems |
| 유제 | **Problem 1** — [링크](https://danotes.mech.uwa.edu.au/threads/problems/problems.html). 수치: Acme 30 mm 1줄 피치 6, 스러스트 칼라 평균지름 40 mm, 나사 μ 0.15, 칼라 μ 0.10, 하중 100 kN. (a) 올림 토크 (b) 1 Hz일 때 동력·효율 (c) 칼라 마찰을 없애면 자립하는지와 내림 토크 (d) μ를 반으로 줄이면? |
| 유형 | 나사 올림 토크, 효율, 자립 판정, 내림 토크 |
| 유사점 | 서현 M1이 이미 (a)만 씀 → 이번에 (a)~(d) 전부 풀어 **M1의 '자립·내림 토크' 판단과 같은 함수**로 대조 |
| 변형 | Acme(α 14.5°)·1줄·리드 6 → Tr8×8(α 15°)·4줄·리드 8, 100 kN → 0.91 N, 칼라 없음. 질문을 "전원이 꺼져도 바닥이 버티나"로 |
| 교재 정답 / 해설집 / AI 재풀이 | (a) **501 N·m** / — / **501.2 N·m** (sec α 무시 — 교재와 같은 식) · sec α 넣으면 508.0 (서현 수기 508과 일치) (b) **3.15 kW, 19 %** / — / 3.15 kW, 19.1 % (c) **자립, 106 N·m** / — / 자립, 105.9 N·m (d) 정답 없음 / — / μ 0.075에서도 πμd_m = 6.36 > l = 6 → **아직 자립 (여유 0.36 mm)**, 윤활이 더 좋아지면 풀릴 수 있음 |
| 본인 풀이 / 대조 | 대기 (수기 칸) / AI–정답 0.04 %·0 %·0.5 %·0.11 % |

④ 수기 풀이 — 대기. 순서: d_m = d − p/2 → T_R = (F d_m/2)(l + π μ d_m)/(π d_m − μ l) + F μ_c d_c/2 → P = 2π f T, η = F l/(2πT) → 자립: π μ d_m > l → T_L = (F d_m/2)(π μ d_m − l)/(π d_m + μ l)

⑤ 우리 설계 적용 (M1)
- Tr8×8: 리드각 20.0° > 마찰각 8.8° → 자립 안 함 (서현 M1과 같음). **자립하려면 μ ≥ 0.351** (= l cos α/(π d_m)) — 황동–스테인리스 건조 0.15로는 불가 → 서현 결론(감속기가 잡아 줌, J6 확인) 유지
- 교재 (d)의 교훈: 자립 여유가 작은 나사는 윤활로 풀릴 수 있음 → 우리 나사는 처음부터 자립 아님이므로 **'전원 끔 → 바닥 하강' 시험(J6)이 필수**

### ME2 압축 코일 스프링 강성·밀착 응력·피로 — 기계요소설계 (M3·스프링 204 연결)
③ 교과서 유제 연계
| 항목 | 내용 |
|---|---|
| 교재명 | Wright, DANotes — Springs: Tutorial problems + Springs fatigue (식 4a: τ_m/S_us + τ_a/S_es = 1/n) |
| 유제 | **Problem 2** — [링크](https://danotes.mech.uwa.edu.au/springs/problems/problems.html). 수치: 평균 코일 지름 76, 선 지름 12.5, 유효 5감김, 자유 길이 140 mm, ASTM A229 오일 템퍼선, 끝 처리는 문제 모음 머리말대로 '맞대고 연삭'. (a) 강성 (b) 밀착 응력 (c) 2~3 kN 변동 하중의 안전율 |
| 유형 | 스프링 강성 k = G d⁴/(8 D³ N_a), 밀착 응력, Goodman형 피로 안전율 |
| 유사점 | 홀더 스프링 204가 **'찍는 힘 상한'을 정하는 압축 코일 스프링** (S4 M3, D6 F_s 0~0.18 N) — 같은 식으로 크기를 정함 |
| 변형 | 하중 kN → 0.1 N대, A229 → 피아노선, 피로 → 정적(찍는 횟수 적음, 응력 낮음) |
| 교재 정답 / 해설집 / AI 재풀이 | (a) **110 N/mm** / — / **110.3** (G 79.3 GPa — A229 표값 77.2 GPa면 107) (b) **619 MPa** / — / **620.8** (밀착 하중 5.79 kN, 직접 전단 보정 K_s = 1 + 0.5/C) (c) **1.3** / — / **1.28** (S_ut = 1855/d^0.187 = 1157 MPa (Shigley A229 상수), S_us = 0.63 S_ut, S_es = 0.13 S_ut (DANotes 표 2), 평균엔 K_s, 진폭엔 Wahl) |
| 본인 풀이 / 대조 | 대기 / AI–정답 0.24 %·0.28 %·−1.3 % |

④ 수기 풀이 — 대기. 순서: C = D/d → k → N_t = N_a + 2, L_s = d N_t → F_s = k(L_f − L_s) → τ = K 8FD/(πd³) → S_ut → τ_m, τ_a → 1/n = τ_m/S_us + τ_a/S_es
가정 표시: (c)의 진폭 응력 계수 K_h를 Wahl 계수로 봄 [가능성 높음 — DANotes '전체 응력 집중'], S_ut 식은 Shigley 상수 [가능성 높음 — DANotes 표 글자가 깨져 확인 못 함]

⑤ 우리 설계 적용 (스프링 204, **잠정 — F_ink 시험 후 서현이 정함**)
| 항목 | 값 |
|---|---|
| 조건 | 홀더가 눌리는 거리 5 mm (가정)에서 F_s ≤ 0.18 N (S4 M3) → k ≤ 0.036 N/mm |
| 사양 예 | 피아노선(음악선) d 0.25 mm, 코일 평균지름 6 mm (C = 24), **유효 감김 약 5.1** |
| 응력 | 0.18 N에서 τ = 180 MPa, S_sy ≈ 0.45 S_ut = 1216 MPa → **정적 안전율 6.8** |
| 걸리는 점 | C = 24는 감기 어려운 축(보통 4~12) → 시중 미니 스프링 중 k가 낮은 것을 사서 쓰거나, 스프링 없이 자중(0.32 N)만으로 되는지 먼저 (D6) |
