## 동작 순서 (상태 머신) — 2차 (D5 4차)
`design/2026-10-28_D2_기능시퀀스와_기능계통도.md` 1장 + D5 4차 부품 기준.
1. 대기: 112 열림, 170·176 닫힘, 140 내림, 마커 201은 대기 자리 캡 컵(219)에 앉음(205 놓음) — 카메라 시야 비어 있음
2. 114 감지 → 빛 게이트로 문틈이 빈 것 확인 → 112 닫힘 (닫는 동안 다시 확인)
3. 180 판별 (종·계급·표식·마리 수) → 로그. 방제 모드 / 여왕벌 / 다른 종 / 불확실 / 두 마리 → 8
4. 180으로 말벌이 바닥에 있는지(등이 위) 확인 → 153 상승 (148 힘 상한에서 정지)
5. 180: 등이 위인지 + 흉부 좌표 (x, y) → 아니면 140을 10 mm 내렸다 다시 (최대 N회, 모두 실패 → 표식 없이 7 + 로그 '마킹 실패')
6. 205 들기 → 215·209로 흉부 위 이동 → 205 놓음 (2단계 속도, 마지막 2 mm ≤ 60 °/s, 자중으로 찍음, 필요하면 2~3회) → 205 들기 → 대기 자리 → 205 놓음 (캡 컵) → 180 점 확인 (없으면 6 한 번 더)
7. 급이: 140을 심지(142) 높이에 둔 채 정해진 시간 → 176 열림 → 방생 → 176 닫힘 → 1
8. 격리: 140 내림 → 170 열림 → 포획통으로 → 170 닫힘 → 1
