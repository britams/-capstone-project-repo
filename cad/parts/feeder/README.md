## 어떻게 되어 있나
1. **부품 파일 하나 = 부품 하나.** 부품마다 자기 원점이 있고, 그 원점에서 그린다. 파일 안에는 시트가 두 개 있다.
   - `치수`: 부품 도면에 들어갈 값
   - `맞춤`: 다른 부품과 만나는 자리
2. **조립 파일 `A143_급이방_조립.FCStd`는 모양을 갖지 않는다.** 부품 파일을 App::Link로 불러 자리에 놓기만 한다. 인서트 6개, 손나사 4개, 발 나사 2개는 각각 같은 부품 파일을 가리키는 링크다. 그래서 부품 파일 하나를 고치면 조립의 모든 자리가 함께 바뀐다.
3. **치수를 적는 곳은 하나뿐이다.** 값은 `cad/D5g_feeder_uln.py`의 `FD`·`FDX`·`INS`·`FOOT`에만 적는다. 부품 파일, 조립 파일, `D5g_full`, `feeder_check.py`가 모두 이 값을 읽는다. 두 곳에 적으면 언젠가 어긋나기 때문이다.
4. **다시 만들 때 (PC FreeCAD 1.1):**
   - 만들기: `import feeder_parts as FP; FP.run()`
   - 그림 (GUI 매크로): `freecad.exe cad\feeder_parts_render.py`
