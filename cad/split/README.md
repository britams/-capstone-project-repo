## 규칙
1. **무거운 일은 따로 띄운 FreeCAD 창에서 한다**: `freecad.exe cad\<스크립트>.py` (작업 폴더 = `cad`).
   - 그 창이 멈추거나 죽어도 쓰고 있는 창은 안전하다.
   - 스크립트는 결과를 `split\_*.json`에 쓰고 스스로 닫힌다.
   - `freecadcmd`(GUI 없음)는 못 쓴다. 옛 스크립트가 ViewObject를 바로 쓰기 때문이다.
2. **한 부분만 고친다**: `edit_s1.py`, `edit_s2.py`
   - 둘레 40 mm 안의 다른 부분을 `CTX_`로 잠깐 넣고, 겹침과 움직임을 본 뒤 지운다.
3. **마지막 조립 검사**: `split3_boundary.py`
   - 서로 다른 부분끼리만, 상자가 겹치는 쌍만 계산한다.
   - 모든 쌍의 거리 계산은 금지 — 11/11에 FreeCAD를 멈춘 원인이다.
4. **처음부터 다시 만들기**: `split3_build.py`
   - `G.make()` 후 세 파일로 나눈다 (약 10분).
   - 나눈 뒤 각 파일에서 고친 것은 이것을 돌리면 사라진다. 고친 내용은 스크립트에 있으므로, 다시 만든 뒤 `edit_s*.py`를 다시 돌린다.
5. **산 부품 STEP판은 PC에만 둔다**: `s1_vendor.py` → `capstone design_이서현\CAD files\split\S1_급이부_STEP.FCStd`
   - McMaster CAD는 공개 레포에 올리지 않는다.
   - 레포 파일은 같은 자리에 단순 모양을 쓴다.
