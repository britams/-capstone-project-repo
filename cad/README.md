# cad — FreeCAD 모델과 그림 (시간순)

담당: 서현. 모델은 생성 스크립트(`.py`)로 만들고 `.FCStd`를 함께 올린다. 치수는 `design/`의 설계 변수표(D6)와 상용 트랩 실측표에서 읽는다.
**지금 기준은 D5e다** (아래 7·8번). 서현 PC 사본은 `capstone design_이서현\CAD files\`에 있다 (FCStd + jpg, 11/02 정리).

## 규칙 (서현 지시, 11/01~02)
- 모델을 바꾸면 **그림(PNG/JPG)도 다시 만들어 올린다**. 사람이 바로 볼 수 있어야 한다. 정투영으로 렌더하고, 렌더 전에 시점 전환 애니메이션을 끈다(`setAnimationEnabled(False)`). 켜 두면 시점이 덜 돌아간 채 찍힌다.
- **전체 조립도에는 2020 알루미늄 프로파일 프레임과 상용 트랩을 반드시 같이 그린다.** 모듈만 있는 그림은 "모듈 확대"로만 쓴다.
- 프레임은 **정방형 20 시리즈(2020)만** 쓴다.
- 구매 부품 치수는 제조사 외형도나 McMaster-Carr로 확인하고, 근거를 스크립트 주석에 적는다.
- 이음부(끼움 길이·면 접촉·나사 길)와 움직일 때의 간섭은 `D5e_check.py`로 검사한다. 통과 결과는 json으로 남긴다.
- 저장 위치는 두 곳이다: 레포 `cad/`, 그리고 서현 PC `CAD files\`(FCStd + jpg).

구동기·구매품 치수와 근거:
- 28BYJ-48: Ø28×19, 축 Ø5(D컷 3, 길이 6), 축은 몸통 중심에서 8 mm 치우침, 귀 구멍 간격 35 (부품 외형도)
- SG90: 22.2 × 11.8 × 22.7, 귀 32.2. MG90S: 22.8 × 12.2 × 28.5
- 커플링 5 → 8 mm, Ø19.1 × 25.4 (McMaster-Carr 4147N159와 같은 치수)
- LM8UU Ø15×24, LM6UU Ø12×19

움직이는 법: `D5e_module_kinematic.FCStd`를 열고 스프레드시트 `Joints`의 값을 바꾼 뒤 다시 계산(Ctrl+R)한다. 값은 floor(바닥 0~36.5), xm·ym(마커), horn(펜 서보), support, door_entry·door_iso·door_rel(+60 닫힘 / −60 열림), 말벌 hx·hy·hz·hpitch다.
