## 2. 우리 팀에 주는 의미

1. **[가능성 높음] 한국 현장에서는 VespAI를 "그대로" 쓸 수 없다.** 장수말벌·좀말벌·털보말벌이 오면 학습한 두 클래스 중 하나로 잘못 분류되거나 놓친다. 조사 모드의 "카메라 2차 판별"(D1 Q3 확정)에는 한국 종을 넣은 **재학습**이 필요하다 → 우리 사진 데이터가 필요하고, 그래서 **표본 채집이 비전 쪽에도 급하다.**
2. **[확실] 계급(여왕벌·일벌) 판별은 원래 없다.** 우리 설계의 여왕벌 격리는 카메라가 아니라 크기·기구로 해야 하는지, 아니면 계급 라벨을 직접 만들어 학습할지 정해야 한다 (서현 D3와 연결).
3. **[가능성 높음] 라이선스:** 캡스톤 시제품·발표(비영리)는 문제없다. 그러나 "공공기관 판매"를 사업화 내용으로 쓰려면 ① 저자에게 상용 허가를 받거나 ② 우리 데이터로 **Apache/MIT 계열 모델을 새로 학습**해야 한다. 공개 가중치를 미세조정(파인튜닝)한 모델도 원 라이선스(NC-SA)를 따를 가능성이 높다 [추측 — 법률 해석 필요].
4. VespAI에서 가져갈 것: 학습 하이퍼파라미터(`models/yolov5-params/hyp.vesparams.yaml`), ViBe 움직임 전처리(`monitor/vibe.py`), 미끼판 촬영 방식, 성능 비교 기준(논문 수치).

## 4. 실행 계획

### 4-1. 1단계 — 승준 PC에서 예시 이미지로 실행 (이번 주)
이 Claude 작업 환경에서는 외부 가중치(`.pt`, 피클 형식) 로드가 보안 정책으로 막혀 **실행하지 못했다.** 승준 PC에서 아래대로 한다. 승준 PC의 OS(Windows/macOS)를 알려 주면 명령을 맞춰 준다.

1. Python **3.11 또는 3.12** 설치 (torch 2.3.x는 3.13 미지원)
2. 저장소 받기
   ```
   git clone https://github.com/andrw3000/vespai
   git clone https://github.com/ultralytics/yolov5 vespai/models/yolov5
   cd vespai/models/yolov5 && git checkout 23701eac7a7b160e478ba4bbef966d0af9348251
   ```
3. 가상환경 + 패키지 — **두 방법 중 하나**
   - A (권장, 원본 2024 조합): `pip install torch==2.3.1 torchvision==0.18.1 opencv-python pandas matplotlib seaborn pyyaml requests scipy tqdm pillow filetype`
   - B (최신 torch): 위에서 torch만 최신으로, 실행 전에 환경변수 `TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1` 설정
   - ⚠ 둘 다 `.pt`를 "믿고" 여는 방식이다. **이 저장소 가중치에만** 쓰고, 출처 모를 `.pt`는 열지 말 것.
4. 예시 이미지 검출: `python vision/scripts/run_vespai_examples.py <yolov5 경로> <가중치 경로> <images/example-detections 경로> <결과 폴더>`
5. 결과 확인: 종별 검출 수가 저장소의 원 결과(`labels/`)와 같은지, 장당 추론 시간(초)
6. 결과를 `vision/`에 날짜 파일로 기록 (결과 이미지는 몇 장만, 25 MB 이하)

### 4-2. 2단계 — Pi 5로 옮기기 (11/4~11/7 일정)
| 경로 | 방법 | 판정 |
|---|---|---|
| ① Pi 5 CPU | PC와 같은 PyTorch 코드 그대로. 논문은 Pi 4에서 약 1 Hz | [가능성 높음] 가장 빨리 됨 |
| ② AI HAT+ (Hailo) | `.pt` → ONNX → Hailo 변환 도구로 HEF. 변환 도구는 x86 Linux PC 필요 | [추측] 세부 절차 `미검증` |
| ③ AI 카메라 (IMX500) | 센서 내부 추론용 형식으로 변환·양자화 필요 | [추측] YOLOv5 지원 여부 `미검증` |

→ [가능성 높음] **①로 먼저 동작을 확인하고, 속도가 모자랄 때 ②를 검토**하는 순서가 맞다. 우리 장치는 말벌이 한 마리씩 통로에 들어오는 구조라 초당 여러 장이 필요 없을 수 있다 (서현 D2 시퀀스의 판별 시간 요구와 맞춰 볼 것).

### 4-3. 3단계 — 한국 종으로 재학습 (11월~겨울)
- 필요한 것: 우리 카메라·우리 통로 조명으로 찍은 사진 (등검은말벌·장수말벌·좀말벌·꿀벌 등). **11월이 지나면 실물 촬영이 어려우니 표본을 냉동 보관해 겨울에 촬영**하는 방법이 현실적 [가능성 높음].
- 라벨 도구, 학습 GPU(Colab 등), 라이선스(2-3)는 이때 정한다.

## 5. 정해야 할 것 (승준)
1. 승준 PC OS, Python 설치 여부 → 4-1 명령 맞춤
2. 상용 판매 시나리오를 보고서에 넣을지 → 넣는다면 VespAI 가중치 대신 자체 학습 모델로 가야 함 (서현과 같이)
3. 여왕벌 판별을 카메라로 할지 기구(크기)로 할지 → D3 회의 안건
4. 인수인계 수정 요청(서현 담당): 저장소 주소, "인스턴스 분할" → "박스 검출", 라이선스 — 레포 Issue로 전달
