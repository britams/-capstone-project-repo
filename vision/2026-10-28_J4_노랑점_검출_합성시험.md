# J4 흉부 노랑 점 검출 — 스크립트와 합성 더미 시험

작성: 2026-10-28 · 이승준 (Claude와 정리, CAP-AI-SJ-20)
파일: `vision/scripts/dot_detect.py` (검출), `vision/scripts/make_synthetic_dummies.py` (합성 더미 + 정답 좌표)
마커: 샤피 크리에이티브 **노랑** (10/28 결정) · 카메라 가정: 격자 위 200 mm, 15.6 화소/mm (인터페이스 2차, J3에서 실측 예정)

## 1. 결론

| # | 내용 | 판정 |
|---|---|---|
| 1 | **노랑 마커의 위험**: 등검은말벌은 다리 끝·배 넷째 마디·얼굴이 노랑~주황 → 색만으로 찾으면 오검출 | [가능성 높음] (종 형태) |
| 2 | 대책: 색(HSV) + **크기**(지름 0.6~3.0 mm) + **원형도** + **둘레가 어두운지**(흉부 위인지) 함께 판단, 격자선에 쪼개진 점은 이어 붙임 | [확실] 구현 |
| 3 | 합성 더미 (다리·배띠·얼굴 노랑, 격자, 조명 기울기·흐림·잡음 포함) — **처음 만든 80장으로 조정 후, 다른 시드 100장**: 검출률 **96 %** (48/50), 오검출 **2 %** (1/50), 찾은 점 위치 오차 **0.3 mm 이내** | [확실] 합성 기준 / **실물 `미검증`** |
| 4 | 남은 오검출 1건 = 흉부에서 6.6 mm 떨어진 다리 끝 노랑 조각 → **흉부 둘레만 보게(`--roi`) 하면 걸러짐** → J8(흉부 좌표)과 묶어 쓰는 구조가 맞음 | [가능성 높음] |
| 5 | R5(재포획 인식 90 %) 판단은 **실물 더미 20장 이상**(작업지시 J4 완료 기준)으로 해야 함 — 합성 결과는 코드가 도는지 확인용 | [확실] |

조정 기록: 처음 값(최소 지름 0.8 mm, 이어 붙이기 없음)은 첫 세트에서 87.5 %. 놓친 5장 = 흐림으로 0.9 mm 점이 0.78 mm로 잡힘 3장 + **격자선이 점을 둘로 쪼갬** 2장 → 최소 지름 0.6 mm, 격자선 굵기(0.4 mm)만큼 닫기 연산 추가.

## 2. 쓰는 법
```
python vision/scripts/dot_detect.py 사진.jpg --px-per-mm 15.6 --show 결과.jpg
python vision/scripts/dot_detect.py 사진.jpg --roi 640 480 120      # 흉부 둘레(화소)만
python vision/scripts/dot_detect.py --eval 폴더                     # 파일 이름 dot_… / nodot_… 로 검출률·오검출률
python vision/scripts/make_synthetic_dummies.py 출력폴더 --n 50 --seed 7
```
`--px-per-mm`는 J3 실측값으로 바꿀 것 (지름 판단이 이 값에 달림).

## 3. 실물 시험 (J4 완료 기준) — 승준
1. 검은 더미(검은 펠트·검게 칠한 콩·플라스틱 말벌 모형 등)에 노랑 샤피로 점 1~2 mm를 찍고, 점 없는 것도 같이 준비
2. Pi 5 + AI 카메라를 200 mm 위에서(또는 J3 거리) 격자를 놓고 찍기 — 점 있는 것 `dot_01.jpg…`, 없는 것 `nodot_01.jpg…` 각 20장 이상
3. `--eval`로 검출률(목표 90 %)·오검출률, 틀린 사진은 `--show`로 원인 확인 → `vision/` 날짜 파일에 기록
4. **확인할 위험**: 노랑 다리·배띠가 같은 화면에 있을 때 (실제 말벌 표본이 오면 다시)
